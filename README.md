# Mitch Henderson

I spent seven years working with athletes and coaches in professional rugby. I now work as a data scientist, mostly on statistical modelling and simulation for the kinds of decisions people in sport have to make.

I write the work up at [mitchhenderson.dev](https://mitchhenderson.dev), with the data and code in R and Python.

- [Making 1 rep max estimates more accurate and honest](https://mitchhenderson.dev/posts/2026-01-04-e1rm-modelling/). A Bayesian multilevel model that learns each athlete's strength profile and says how sure it is.
- [How many wins do NRL teams need to make the finals?](https://mitchhenderson.dev/posts/2025-01-18-how-many-wins-do-nrl-teams-need-to-make-the-finals/) Probably 13, from 10,000 simulated seasons.
